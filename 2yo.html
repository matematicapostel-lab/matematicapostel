Ecuaciones Algebraicas

Ejercicio 1

Resuelve:

4x + 8 = 28

¿Cuánto vale x?


Ejercicio resuelto:

4x + 8 = 28

Restamos 8:

4x = 28 - 8

4x = 20

Dividimos entre 4:

x = 20 ÷ 4

x = 5

Respuesta: x = 5

7x = 42

x = 6

Respuesta: x = 6

Números Imaginarios y Complejos

Ejercicio 4

Calcula:

i² + 10

Recuerda: i² = -1


Ejercicio resuelto:

i² + 10

Como:

i² = -1

Sustituimos:

-1 + 10 = 9

Respuesta: 9

Ejercicio 5

Calcula:

i³

Recuerda que i² = -1.


Ejercicio resuelto:

i³ = i² × i

Como i² = -1:

i³ = -1 × i

i³ = -i

Respuesta: -i

Ejercicio 6

Suma los siguientes números complejos:

(3 + 2i) + (5 + 4i)

Escribe el resultado.


Ejercicio resuelto:

(3 + 2i) + (5 + 4i)

Sumamos las partes reales:

3 + 5 = 8

Sumamos las partes imaginarias:

2i + 4i = 6i

Resultado:

8 + 6i

Respuesta: 8 + 6i

Ecuaciones de Segundo Grado

Ejercicio 1

Resuelve:

x² - 5x + 6 = 0

Escribe las soluciones separadas por coma.


Ejercicio resuelto:

x² - 5x + 6 = 0

Factorizamos:

(x - 2)(x - 3) = 0

Entonces:

x - 2 = 0 → x = 2

x - 3 = 0 → x = 3

Respuestas: x = 2 y x = 3

Ejercicio 2

Ejercicio resuelto:

x² - 9 = 0

Sumamos 9:

x² = 9

Sacamos raíz:

x = ±3

Respuestas: x = -3 y x = 3

Ejercicio 3

Resuelve:

x² - 7x + 12 = 0

Escribe las soluciones separadas por coma.


Ejercicio resuelto:

Por lo tanto:

x = 3

x = 4

Respuestas: x = 3 y x = 4

Progresiones Aritméticas

Ejercicio 1

Observa:

5, 8, 11, 14, ...

¿Cuál es el quinto término?


Ejercicio resuelto:

La diferencia es:

8 - 5 = 3

Entonces sumamos 3:

14 + 3 = 17

Quinto término: 17

Ejercicio 2

Una progresión aritmética tiene:

a₁ = 4

d = 3

¿Cuál es el octavo término?


Ejercicio resuelto:

Usamos:

aₙ = a₁ + (n - 1)d

a₈ = 4 + (8 - 1)(3)

a₈ = 4 + 7(3)

a₈ = 4 + 21

a₈ = 25

Octavo término: 25

Ejercicio 3

Observa la progresión:

12, 17, 22, 27, ...

¿Cuál es el décimo término?


Ejercicio resuelto:

a₁ = 12

d = 5

n = 10

Usamos:

aₙ = a₁ + (n - 1)d

a₁₀ = 12 + (10 - 1)(5)

a₁₀ = 12 + 45

a₁₀ = 57

Décimo término: 57

Progresiones Geométricas

Ejercicio 4

Observa:

2, 6, 18, 54, ...

¿Cuál es el quinto término?


Ejercicio resuelto:

La razón es:

6 ÷ 2 = 3

Multiplicamos el cuarto término por 3:

54 × 3 = 162

Quinto término: 162

Ejercicio 5

Una progresión geométrica tiene:

a₁ = 3

r = 2

¿Cuál es el sexto término?


Ejercicio resuelto:

Usamos:

aₙ = a₁ × rⁿ⁻¹

a₆ = 3 × 2⁵

2⁵ = 32

a₆ = 3 × 32

a₆ = 96

Sexto término: 96

Ejercicio 6

Observa:

5, 15, 45, 135, ...

¿Cuál es el quinto término?


Ejercicio resuelto:

La razón es:

15 ÷ 5 = 3

Entonces:

135 × 3 = 405

Quinto término: 405
