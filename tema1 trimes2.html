Ecuaciones de Segundo Grado

tema 1 - 2do trimestre

1. Introducción

Las ecuaciones de segundo grado, también llamadas ecuaciones cuadráticas, son ecuaciones algebraicas en las que la incógnita aparece elevada al cuadrado.

Por ejemplo:

x² + 5x + 6 = 0

El mayor exponente de la incógnita es 2, por eso se denomina ecuación de segundo grado.

Definición:

Una ecuación de segundo grado es una ecuación que puede expresarse en la forma general:

ax² + bx + c = 0

donde a ≠ 0.

2. Forma general

La forma general de una ecuación de segundo grado es:

ax² + bx + c = 0

Cada letra representa un elemento diferente:

a: coeficiente del término cuadrático.
b: coeficiente del término lineal.
c: término independiente.

Es importante recordar que:

a ≠ 0

3. Identificación de los coeficientes

Observemos la siguiente ecuación:

3x² + 7x - 10 = 0

Podemos identificar:

a = 3
b = 7
c = -10

Estos valores serán necesarios cuando utilicemos la fórmula general.

4. Tipos de ecuaciones de segundo grado

Ecuación completa

Tiene los tres términos:

ax² + bx + c = 0

Ejemplo:

2x² + 5x - 3 = 0

Ecuación incompleta sin término independiente

ax² + bx = 0

Ejemplo:

x² + 4x = 0

Ecuación incompleta sin término lineal

ax² + c = 0

Ejemplo:

x² - 25 = 0

5. Métodos para resolver ecuaciones cuadráticas

Existen diferentes métodos para resolver una ecuación de segundo grado.

Factorización.
Extracción de raíz cuadrada.
Fórmula general.
Completando el cuadrado.

El método que utilizaremos con mayor frecuencia será la fórmula general.

6. Fórmula general

Para una ecuación:

ax² + bx + c = 0

utilizamos la siguiente fórmula:

x = (-b ± √(b² - 4ac)) / 2a

El símbolo ± significa que debemos realizar dos operaciones: una utilizando el signo + y otra utilizando el signo -.

Indicaciones:

Antes de utilizar la fórmula general identifica correctamente los valores de a, b y c.

7. El discriminante

La expresión que aparece dentro de la raíz cuadrada se llama discriminante.

Δ = b² - 4ac

El discriminante permite saber cuántas soluciones reales tiene una ecuación.

Si Δ > 0: existen dos soluciones reales diferentes.
Si Δ = 0: existe una solución real doble.
Si Δ < 0: no existen soluciones reales.

8. Ejemplo básico por factorización

Ejemplo: x² + 5x + 6 = 0

Paso 1: Buscamos dos números que multiplicados den 6 y sumados den 5.

2 × 3 = 6
2 + 3 = 5

Paso 2: Factorizamos.

(x + 2)(x + 3) = 0

Paso 3: Igualamos cada factor a cero.

x + 2 = 0
x + 3 = 0

Paso 4: Despejamos.

x₁ = -2
x₂ = -3
Soluciones: x₁ = -2 y x₂ = -3

9. Ejemplo por extracción de raíz

Ejemplo: x² - 25 = 0

Paso 1: Pasamos 25 al otro miembro.

x² = 25

Paso 2: Aplicamos raíz cuadrada.

x = ±√25

Paso 3:

x = ±5
Soluciones: x₁ = 5 y x₂ = -5

10. Ejemplo con fórmula general

Ejemplo: x² - 5x + 6 = 0

Paso 1: Identificamos a, b y c.

a = 1
b = -5
c = 6

Paso 2: Aplicamos la fórmula.

x = (-b ± √(b² - 4ac)) / 2a

Paso 3: Sustituimos los valores.

x = (5 ± √((-5)² - 4(1)(6))) / 2

Paso 4: Calculamos el discriminante.

(-5)² - 4(1)(6)

25 - 24 = 1

Paso 5: Sustituimos.

x = (5 ± √1) / 2
x = (5 ± 1) / 2

Paso 6: Obtenemos las dos soluciones.

x₁ = (5 + 1) / 2 = 3

x₂ = (5 - 1) / 2 = 2
Soluciones: x₁ = 3 y x₂ = 2

11. Ecuaciones incompletas

Ejemplo: 2x² - 18 = 0

Paso 1: Pasamos el término independiente.

2x² = 18

Paso 2: Dividimos entre 2.

x² = 9

Paso 3: Sacamos raíz cuadrada.

x = ±3
Soluciones: x₁ = 3 y x₂ = -3

12. Ejercicios de mayor dificultad

Indicaciones:

En los siguientes ejercicios utilizaremos varios procedimientos. Observa cuidadosamente cada paso.

Recuerda:

ax² + bx + c = 0

Primero identifica los valores de a, b y c. Después calcula el discriminante y finalmente encuentra las soluciones.

Ejercicio 1: 2x² + 7x + 3 = 0

Paso 1: Identificamos los coeficientes.

a = 2
b = 7
c = 3

Paso 2: Aplicamos la fórmula general.

x = (-7 ± √(7² - 4(2)(3))) / 4

Paso 3: Calculamos el discriminante.

49 - 24 = 25

Paso 4: Sacamos la raíz.

√25 = 5

Paso 5: Calculamos las soluciones.

x₁ = (-7 + 5) / 4
x₁ = -2 / 4
x₁ = -1/2
x₂ = (-7 - 5) / 4
x₂ = -12 / 4
x₂ = -3
Soluciones: x₁ = -1/2 y x₂ = -3

Ejercicio 2: 3x² - 10x + 3 = 0

Paso 1: Identificamos:

a = 3
b = -10
c = 3

Paso 2: Calculamos el discriminante.

Δ = (-10)² - 4(3)(3)
Δ = 100 - 36
Δ = 64

Paso 3: Aplicamos la fórmula.

x = (10 ± √64) / 6
x = (10 ± 8) / 6

Paso 4: Primera solución.

x₁ = (10 + 8) / 6
x₁ = 18 / 6
x₁ = 3

Paso 5: Segunda solución.

x₂ = (10 - 8) / 6
x₂ = 2 / 6
x₂ = 1/3
Soluciones: x₁ = 3 y x₂ = 1/3

Ejercicio 3: 4x² - 4x - 15 = 0

Paso 1: Identificamos los coeficientes.

a = 4
b = -4
c = -15

Paso 2: Calculamos el discriminante.

Δ = (-4)² - 4(4)(-15)
Δ = 16 + 240
Δ = 256

Paso 3: Calculamos la raíz.

√256 = 16

Paso 4: Aplicamos la fórmula.

x = (4 ± 16) / 8

Paso 5: Primera solución.

x₁ = (4 + 16) / 8
x₁ = 20 / 8
x₁ = 5/2

Paso 6: Segunda solución.

x₂ = (4 - 16) / 8
x₂ = -12 / 8
x₂ = -3/2
Soluciones: x₁ = 5/2 y x₂ = -3/2

Ejercicio 4: x² + 6x + 10 = 0

Este ejercicio es especial porque el discriminante será negativo.

Paso 1: Identificamos:

a = 1
b = 6
c = 10

Paso 2: Calculamos el discriminante.

Δ = 6² - 4(1)(10)
Δ = 36 - 40
Δ = -4

Paso 3: Como el discriminante es negativo, no existen soluciones reales.

No existen soluciones reales.

La ecuación tiene soluciones complejas.

Ejercicio 5: 5x² - 20x + 20 = 0

Paso 1: Identificamos:

a = 5
b = -20
c = 20

Paso 2: Calculamos el discriminante.

Δ = (-20)² - 4(5)(20)
Δ = 400 - 400
Δ = 0

Paso 3: Como Δ = 0, existe una única solución real.

x = -(-20) / 2(5)
x = 20 / 10
x = 2
Solución doble: x = 2

Ejercicio 6: Reto final

6x² + x - 2 = 0

Paso 1: Identificamos:

a = 6
b = 1
c = -2

Paso 2: Calculamos el discriminante.

Δ = 1² - 4(6)(-2)
Δ = 1 + 48
Δ = 49

Paso 3: Calculamos la raíz.

√49 = 7

Paso 4: Aplicamos la fórmula general.

x = (-1 ± 7) / 12

Paso 5: Primera solución.

x₁ = (-1 + 7) / 12
x₁ = 6 / 12
x₁ = 1/2

Paso 6: Segunda solución.

x₂ = (-1 - 7) / 12
x₂ = -8 / 12
x₂ = -2/3
Soluciones: x₁ = 1/2 y x₂ = -2/3

13. Comprobación de las soluciones

Una vez obtenidas las soluciones, podemos comprobarlas reemplazándolas en la ecuación original.

Ejemplo:

x² - 5x + 6 = 0

Obtuvimos:

x₁ = 3

Reemplazamos:

3² - 5(3) + 6 = 0

9 - 15 + 6 = 0

0 = 0
La solución es correcta.

14. Indicaciones importantes

Ordena la ecuación antes de comenzar.
Procura que la ecuación tenga la forma ax² + bx + c = 0.
Identifica correctamente a, b y c.
Ten cuidado con los signos negativos.
Calcula correctamente el discriminante.
Recuerda que el símbolo ± produce dos posibles soluciones.
Simplifica las respuestas cuando sea posible.
Comprueba las soluciones en la ecuación original.

15. Resumen del tema

Las ecuaciones de segundo grado son ecuaciones donde la mayor potencia de la incógnita es 2.

ax² + bx + c = 0

La fórmula general permite encontrar sus soluciones:

x = (-b ± √(b² - 4ac)) / 2a

El discriminante es:

Δ = b² - 4ac

Según su valor podemos saber el tipo de solución:

Δ > 0: dos soluciones reales diferentes.
Δ = 0: una solución real doble.
Δ < 0: no existen soluciones reales.
Objetivo principal: resolver ecuaciones de segundo grado utilizando correctamente los diferentes métodos.
