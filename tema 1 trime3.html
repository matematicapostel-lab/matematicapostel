Progresiones Aritméticas y Geométricas

tema1-3cer trimestre

1. Introducción

Las progresiones son sucesiones de números que siguen una determinada regla de formación.

Son utilizadas para estudiar patrones numéricos, calcular cantidades, predecir valores y resolver diferentes problemas matemáticos.

Ejemplo:

2, 4, 6, 8, 10, ...

En esta sucesión se suma siempre 2 para obtener el siguiente número.

2. Sucesiones numéricas

Una sucesión es un conjunto ordenado de números que siguen una regla determinada.

Cada número de la sucesión recibe el nombre de término.

a₁, a₂, a₃, a₄, a₅, ...

Donde:

a₁ = primer término.

a₂ = segundo término.

a₃ = tercer término.

aₙ = término en la posición n.

3. Progresión Aritmética

Una progresión aritmética (P.A.) es una sucesión en la que cada término se obtiene sumando o restando una cantidad constante llamada diferencia común.

aₙ = a₁ + (n - 1)d

Donde:

aₙ = término que queremos encontrar.

a₁ = primer término.

n = posición del término.

d = diferencia común.

4. Diferencia común

La diferencia común se obtiene restando un término menos el término anterior.

d = a₂ - a₁

Ejemplo

5, 9, 13, 17, 21, ...

Calculamos:

9 - 5 = 4

13 - 9 = 4

17 - 13 = 4

La diferencia común es d = 4.

5. Término general de una progresión aritmética

Para encontrar cualquier término de una progresión aritmética utilizamos:

aₙ = a₁ + (n - 1)d

Ejemplo

Encuentra el término número 20 de:

3, 7, 11, 15, ...

Paso 1: Identificamos los datos.

a₁ = 3

d = 4

n = 20

Paso 2: Aplicamos la fórmula.

a₂₀ = 3 + (20 - 1)(4)

Paso 3: Resolvemos.

a₂₀ = 3 + 19(4)

a₂₀ = 3 + 76

a₂₀ = 79

6. Suma de los términos de una P.A.

Cuando necesitamos sumar varios términos de una progresión aritmética podemos utilizar:

Sₙ = n(a₁ + aₙ) / 2

Ejemplo

Calcula la suma de los primeros 20 términos:

2, 5, 8, 11, ...

Paso 1: Identificamos:

a₁ = 2

d = 3

n = 20

Paso 2: Encontramos a₂₀.

a₂₀ = 2 + (20 - 1)(3)

a₂₀ = 2 + 57

a₂₀ = 59

Paso 3: Aplicamos la fórmula de la suma.

S₂₀ = 20(2 + 59) / 2

Paso 4:

S₂₀ = 20(61) / 2

S₂₀ = 10(61)

S₂₀ = 610

7. Progresión Geométrica

Una progresión geométrica (P.G.) es una sucesión en la que cada término se obtiene multiplicando el término anterior por una cantidad constante llamada razón.

aₙ = a₁ · rⁿ⁻¹

Donde:

aₙ = término que queremos encontrar.

a₁ = primer término.

n = posición del término.

r = razón común.

8. Razón de una progresión geométrica

La razón se obtiene dividiendo un término entre el término anterior.

r = a₂ / a₁

Ejemplo

3, 6, 12, 24, 48, ...

Calculamos:

6 / 3 = 2

12 / 6 = 2

24 / 12 = 2

La razón es r = 2.

9. Diferencia entre P.A. y P.G.

Progresión Aritmética

Se suma o resta siempre la misma cantidad.

Ejemplo:

4, 7, 10, 13, 16, ...

d = 3

Progresión Geométrica

Se multiplica o divide siempre por la misma cantidad.

Ejemplo:

4, 8, 16, 32, 64, ...

r = 2

Recuerda:

P.A. → se utiliza una diferencia.

P.G. → se utiliza una razón.

10. Suma de una progresión geométrica

Para sumar los primeros términos de una progresión geométrica utilizamos:

Sₙ = a₁(rⁿ - 1) / (r - 1)

Esta fórmula se utiliza cuando r ≠ 1.

Ejemplo

Calcula la suma:

2 + 4 + 8 + 16 + 32

Paso 1:

a₁ = 2

r = 2

n = 5

Paso 2: Aplicamos la fórmula.

S₅ = 2(2⁵ - 1) / (2 - 1)

Paso 3:

2⁵ = 32

S₅ = 2(32 - 1) / 1

Paso 4:

S₅ = 2(31)

S₅ = 62

11. Ejercicios de mayor dificultad

Ejercicio 1: Encontrar un término lejano de una P.A.

Encuentra el término número 50 de:

7, 12, 17, 22, ...
Paso 1: Identificamos:

a₁ = 7

d = 5

n = 50

Paso 2: Aplicamos:

aₙ = a₁ + (n - 1)d

a₅₀ = 7 + (50 - 1)(5)

Paso 3:

a₅₀ = 7 + 49(5)

a₅₀ = 7 + 245

a₅₀ = 252

Ejercicio 2: Encontrar la diferencia

En una progresión aritmética, el primer término es 8 y el término número 15 es 78. Encuentra la diferencia común.

Paso 1:

a₁ = 8

a₁₅ = 78

n = 15

Paso 2: Utilizamos:

aₙ = a₁ + (n - 1)d

78 = 8 + (15 - 1)d

Paso 3:

78 = 8 + 14d

70 = 14d

Paso 4:

d = 70 / 14

d = 5

Ejercicio 3: Suma de una P.A.

Calcula la suma de los primeros 30 términos de:

5, 9, 13, 17, ...
Paso 1:

a₁ = 5

d = 4

n = 30

Paso 2: Encontramos el término 30.

a₃₀ = 5 + (30 - 1)(4)

a₃₀ = 5 + 116

a₃₀ = 121

Paso 3: Aplicamos la suma.

S₃₀ = 30(5 + 121) / 2

Paso 4:

S₃₀ = 30(126) / 2

S₃₀ = 15(126)

S₃₀ = 1890

Ejercicio 4: Término de una P.G.

Encuentra el término número 10 de:

3, 6, 12, 24, ...
Paso 1:

a₁ = 3

r = 2

n = 10

Paso 2: Aplicamos:

aₙ = a₁ · rⁿ⁻¹

a₁₀ = 3 · 2⁹

Paso 3:

2⁹ = 512

a₁₀ = 3 · 512

a₁₀ = 1536

Ejercicio 5: Encontrar la razón

En una progresión geométrica, el primer término es 5 y el cuarto término es 135. Encuentra la razón positiva.

Paso 1:

a₁ = 5

a₄ = 135

n = 4

Paso 2:

aₙ = a₁ · rⁿ⁻¹

135 = 5 · r³

Paso 3: Dividimos entre 5.

27 = r³

Paso 4: Sacamos raíz cúbica.

r = ∛27

r = 3

Ejercicio 6: Suma de una P.G.

Calcula la suma de los primeros 8 términos de:

4, 12, 36, 108, ...
Paso 1:

a₁ = 4

r = 3

n = 8

Paso 2: Aplicamos:

Sₙ = a₁(rⁿ - 1) / (r - 1)

S₈ = 4(3⁸ - 1) / (3 - 1)

Paso 3:

3⁸ = 6561

S₈ = 4(6561 - 1) / 2

Paso 4:

S₈ = 4(6560) / 2

S₈ = 2(6560)

S₈ = 13120

Ejercicio 7: Problema aplicado a una P.A.

Una persona ahorra Bs 20 durante la primera semana y aumenta su ahorro en Bs 10 cada semana. ¿Cuánto ahorrará durante la semana número 12?

Paso 1:

a₁ = 20

d = 10

n = 12

Paso 2:

a₁₂ = 20 + (12 - 1)(10)

Paso 3:

a₁₂ = 20 + 110

En la semana 12 ahorrará Bs 130.

Ejercicio 8: Problema aplicado a una P.G.

Una cantidad de bacterias se duplica cada hora. Si inicialmente existen 250 bacterias, ¿cuántas habrá después de 6 horas?

Paso 1:

a₁ = 250

r = 2

Después de 6 horas:

n = 7

porque el valor inicial corresponde al momento 0.

Paso 2:

a₇ = 250 · 2⁶

Paso 3:

2⁶ = 64

a₇ = 250 · 64

Después de 6 horas habrá 16 000 bacterias.

12. Indicaciones importantes

1. Primero identifica si la sucesión es aritmética o geométrica.

2. En una P.A. se suma o resta una cantidad constante.

3. En una P.G. se multiplica o divide por una cantidad constante.

4. Para una P.A. utiliza:

aₙ = a₁ + (n - 1)d

5. Para una P.G. utiliza:

aₙ = a₁ · rⁿ⁻¹

6. Antes de utilizar una fórmula identifica correctamente el primer término, la posición y la diferencia o razón.

7. Lee cuidadosamente el problema para determinar si se necesita encontrar un término o una suma.

13. Resumen

Las progresiones son sucesiones numéricas que siguen una regla.

Progresión Aritmética

Se suma o resta una cantidad constante llamada diferencia.

aₙ = a₁ + (n - 1)d

Progresión Geométrica

Se multiplica o divide por una cantidad constante llamada razón.

aₙ = a₁ · rⁿ⁻¹

Las progresiones permiten reconocer patrones y resolver problemas relacionados con cantidades que aumentan o disminuyen de manera regular.
