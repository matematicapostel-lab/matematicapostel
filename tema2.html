Números Imaginarios y Complejos

tema 2 - 1mer trimestre

1. Introducción

Los números imaginarios y complejos aparecen cuando necesitamos resolver operaciones y ecuaciones que no pueden resolverse utilizando solamente los números reales.

Un ejemplo sencillo es:

x² + 1 = 0

Si despejamos:

x² = -1

Pero ningún número real elevado al cuadrado da como resultado un número negativo.

Para solucionar este tipo de situaciones se utiliza la unidad imaginaria i.

2. La unidad imaginaria

La unidad imaginaria se representa mediante la letra i. Se define de la siguiente manera:

i = √−1

Por lo tanto:

i² = −1

Esta propiedad es fundamental para trabajar con números imaginarios y complejos.

Importante:

La unidad imaginaria permite trabajar matemáticamente con raíces cuadradas de números negativos.

3. Números imaginarios

Un número imaginario es un número que contiene la unidad imaginaria i.

bi

donde b es un número real.

Ejemplos:

3i
−5i
8i
12i

Todos estos son números imaginarios.

4. Potencias de i

Las potencias de i siguen un patrón que se repite cada cuatro potencias.

i¹ = i

i² = −1

i³ = −i

i⁴ = 1

Después de i⁴ el ciclo vuelve a comenzar:

i⁵ = i

i⁶ = −1
Indicaciones:

Cuando tengas una potencia grande de i, puedes dividir el exponente entre 4 y utilizar el residuo para encontrar el resultado.

5. Ejemplos con potencias de i

Ejemplo 1: i⁶

Sabemos que:

i⁴ = 1

Entonces:

i⁶ = i⁴ · i²
i⁶ = 1 · (−1)
i⁶ = −1

Ejemplo 2: i⁷

Descomponemos la potencia:

i⁷ = i⁴ · i³

Sabemos que:

i⁴ = 1

i³ = −i

Entonces:

i⁷ = 1(−i)
i⁷ = −i

Ejemplo 3: i¹⁰

Descomponemos:

i¹⁰ = i⁸ · i²

Como:

i⁸ = 1

Entonces:

i¹⁰ = 1(−1)
i¹⁰ = −1

6. Números complejos

Un número complejo está formado por una parte real y una parte imaginaria.

z = a + bi

Donde:

a = parte real.
b = coeficiente de la parte imaginaria.
i = unidad imaginaria.

Ejemplo:

z = 5 + 3i

La parte real es 5 y la parte imaginaria es 3i.

7. Representación de un número complejo

Los números complejos pueden representarse mediante dos partes:

Eje real: representa la parte real.
Eje imaginario: representa la parte imaginaria.

Por ejemplo:

z = 3 + 2i

El número se representa mediante el punto:

(3 , 2)

El primer valor corresponde a la parte real y el segundo a la parte imaginaria.

8. Suma de números complejos

Para sumar números complejos debemos sumar las partes reales entre sí y las partes imaginarias entre sí.

(a + bi) + (c + di)

= (a + c) + (b + d)i

Ejemplo:

(3 + 4i) + (5 + 2i)

Paso 1: Sumamos las partes reales.

3 + 5 = 8

Paso 2: Sumamos las partes imaginarias.

4i + 2i = 6i

Paso 3: Unimos los resultados.

8 + 6i
Resultado: 8 + 6i

9. Resta de números complejos

Para restar números complejos realizamos el mismo procedimiento: restamos las partes reales y después las partes imaginarias.

(a + bi) − (c + di)

= (a − c) + (b − d)i

Ejemplo:

(8 + 7i) − (3 + 2i)

Paso 1: Restamos las partes reales.

8 − 3 = 5

Paso 2: Restamos las partes imaginarias.

7i − 2i = 5i

Paso 3:

5 + 5i
Resultado: 5 + 5i

10. Multiplicación de números complejos

Para multiplicar números complejos utilizamos la propiedad distributiva.

Debemos recordar que:

i² = −1

Ejemplo:

(2 + 3i)(4 + 5i)

Paso 1: Multiplicamos cada término.

2(4) + 2(5i) + 3i(4) + 3i(5i)

Paso 2: Realizamos las multiplicaciones.

8 + 10i + 12i + 15i²

Paso 3: Como i² = −1:

8 + 10i + 12i + 15(−1)

Paso 4: Reducimos términos semejantes.

8 − 15 + 22i
−7 + 22i
Resultado: −7 + 22i

11. División de números complejos

Para dividir números complejos utilizamos el conjugado del denominador.

Conjugado

El conjugado de:

a + bi

es:

a − bi

Al multiplicar un número complejo por su conjugado obtenemos un número real.

(a + bi)(a − bi) = a² + b²

Ejemplo:

(3 + 2i) / (1 + i)

Paso 1: Buscamos el conjugado del denominador.

Conjugado de 1 + i = 1 − i

Paso 2: Multiplicamos numerador y denominador por el conjugado.

(3 + 2i)(1 − i)

————————————

(1 + i)(1 − i)

Paso 3: Resolvemos el numerador.

3 − 3i + 2i − 2i²

Como i² = −1:

3 − i + 2
5 − i

Paso 4: Resolvemos el denominador.

1 − i²
1 − (−1) = 2

Paso 5: Escribimos el resultado.

(5 − i) / 2
Resultado: 5/2 − 1/2i

12. Módulo de un número complejo

El módulo representa la distancia desde el origen hasta el punto que representa al número complejo.

Para:

z = a + bi

el módulo se calcula mediante:

|z| = √(a² + b²)

Ejemplo:

z = 3 + 4i

Paso 1: Identificamos los valores.

a = 3

b = 4

Paso 2: Aplicamos la fórmula.

|z| = √(3² + 4²)

Paso 3:

|z| = √(9 + 16)
|z| = √25
|z| = 5
Módulo = 5

13. Ejercicios de mayor dificultad

Indicaciones:

Estos ejercicios reúnen diferentes operaciones con números imaginarios y complejos.

Recuerda utilizar siempre:

i² = −1

Organiza cada operación por pasos y reduce los términos semejantes antes de obtener el resultado final.

Ejercicio 1

(4 + 3i) + (7 − 5i) − (2 + i)

Paso 1: Agrupamos las partes reales.

4 + 7 − 2 = 9

Paso 2: Agrupamos las partes imaginarias.

3i − 5i − i = −3i

Paso 3: Unimos ambas partes.

Resultado: 9 − 3i

Ejercicio 2

(3 + 2i)(5 − 4i)

Paso 1: Aplicamos la propiedad distributiva.

3(5) + 3(−4i) + 2i(5) + 2i(−4i)

Paso 2: Multiplicamos.

15 − 12i + 10i − 8i²

Paso 3: Utilizamos i² = −1.

15 − 12i + 10i + 8

Paso 4: Reducimos términos semejantes.

23 − 2i
Resultado: 23 − 2i

Ejercicio 3

(2 − 3i)²

Paso 1: Escribimos la multiplicación.

(2 − 3i)(2 − 3i)

Paso 2: Aplicamos la propiedad distributiva.

4 − 6i − 6i + 9i²

Paso 3: Reemplazamos i² por −1.

4 − 12i − 9

Paso 4: Simplificamos.

−5 − 12i
Resultado: −5 − 12i

Ejercicio 4: Potencia de i

i²⁷

Paso 1: Dividimos el exponente entre 4.

27 ÷ 4 = 6

Residuo = 3

Paso 2: Utilizamos el residuo 3.

i³ = −i
Resultado: i²⁷ = −i

Ejercicio 5: Operación combinada

(2 + i)(3 − 2i) + (4 − 3i)

Paso 1: Multiplicamos los primeros paréntesis.

6 − 4i + 3i − 2i²

Paso 2: Sustituimos i² = −1.

6 − 4i + 3i + 2

Paso 3: Reducimos.

8 − i

Paso 4: Sumamos el segundo número complejo.

(8 − i) + (4 − 3i)
12 − 4i
Resultado: 12 − 4i

Ejercicio 6: Módulo

z = −6 + 8i

Paso 1: Aplicamos la fórmula del módulo.

|z| = √(a² + b²)

Paso 2: Reemplazamos los valores.

|z| = √((-6)² + 8²)

Paso 3: Calculamos los cuadrados.

|z| = √(36 + 64)

Paso 4:

|z| = √100
Resultado: |z| = 10

Ejercicio 7: Reto final

(1 + 2i)(3 + 4i) − (2 − i)

Paso 1: Multiplicamos los primeros términos.

3 + 4i + 6i + 8i²

Paso 2: Sustituimos i² = −1.

3 + 10i − 8
−5 + 10i

Paso 3: Restamos el segundo número complejo.

(−5 + 10i) − (2 − i)

Paso 4: Distribuimos el signo negativo.

−5 + 10i − 2 + i

Paso 5: Reducimos términos semejantes.

−7 + 11i
Resultado final: −7 + 11i

14. Indicaciones importantes

Recuerda siempre que i² = −1.
Separa la parte real de la parte imaginaria.
Reduce términos semejantes.
En las multiplicaciones utiliza la propiedad distributiva.
En las divisiones utiliza el conjugado del denominador.
En las potencias de i utiliza el ciclo de cuatro valores.
Realiza las operaciones paso a paso.

15. Resumen del tema

Los números imaginarios permiten trabajar con raíces cuadradas de números negativos.

i = √−1

i² = −1

Los números complejos tienen la forma:

z = a + bi

Para trabajar con números complejos debemos aprender a sumar, restar, multiplicar y dividir sus partes correctamente.

También podemos calcular su módulo y representar los números complejos mediante un plano con una parte real y una parte imaginaria.

Objetivo principal: comprender y operar correctamente con números imaginarios y complejos.
